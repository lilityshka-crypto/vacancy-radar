Privacy Policy

Effective date: November 6, 2026

Vacancy Radar (“the app”) is a personal job-search tool operated by an individual developer (GitHub user lilityshka-crypto, “we”). The app is used only by its owner. This policy explains what data the app accesses through the Threads API and how it is handled.

Data we access

  • Owner’s Threads profile (permission threads_basic): the Threads user ID and username of the owner, used only to confirm that sign-in worked.
  • Public Threads posts (permission threads_keyword_search): posts returned by keyword search for job-related terms. For each post the app reads the post ID, text, permalink, publication time, the author’s username and whether the post has replies.

The app does not access private messages, follower lists, passwords, or any data of other Threads users beyond the public posts listed above.

How we use the data

  • To decide whether a public post is a job offer for a designer, its text is checked with keyword rules and, if it passes, analyzed by the Anthropic Claude API.
  • Relevant posts (summary, author username and link to the original post) are sent to the owner’s private Telegram chat.

We do not use the data for advertising, profiling, or training AI models, and we never sell it.

Storage and retention

  • To avoid duplicate notifications, the app stores post IDs, normalized post links and short one-way hashes of post text for up to 60 days. The text of posts is not stored.
  • The owner’s Threads access token is stored encrypted and is used only to call the Threads API.

Service providers

The app runs on GitHub Actions (GitHub, Inc.). Post text is sent to Anthropic, PBC (Claude API) for analysis. Notifications are delivered through Telegram. These providers process data only to perform these functions. Data obtained through the Threads API is not shared with anyone else.

Your choices and data deletion

The owner can revoke the app’s access at any time in Threads: Settings → Account → Website permissions. If you are the author of a public post and want any stored identifiers related to it deleted, follow the instructions on the Data Deletion page. We complete requests within 30 days.

Changes and contact

We will update this page if the app’s data practices change. Questions: open an issue on GitHub.
